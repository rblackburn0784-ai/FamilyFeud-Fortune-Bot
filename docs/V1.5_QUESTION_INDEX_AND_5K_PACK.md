# V1.5 — Question Index & 5k Checked Pack

V1.5 is a performance and content release.

It adds:

- `feudbot/question_index.py`
- `tools/build_v1_5_question_pack.py`
- `tools/apply_v1_5_question_index.py`
- optional generated pack: `v1_5_questions.json`
- indexed category/pack lookup for the larger pool

## Why this exists

The bot already had about 2,000 bundled boards. V1.5 adds a deterministic builder for roughly 3,000 extra checked boards, bringing the practical bundled pool to about 5,000 questions after generation.

The extra pack is generated locally so the repository does not need to carry a massive raw JSON file in every commit.

## Build the V1.5 pack

Run from the project root:

```powershell
.\.venv\Scripts\python.exe tools\build_v1_5_question_pack.py
```

This creates:

```text
v1_5_questions.json
reports/v1_5_question_pack_report.md
```

The builder checks:

- survey-style wording
- category validity
- 6 answers per board
- descending point values
- duplicate question text
- duplicate answer text
- alias sanity

## Apply the bot patch

After generating the pack, run:

```powershell
.\.venv\Scripts\python.exe tools\apply_v1_5_question_index.py
```

Then run:

```powershell
.\.venv\Scripts\python.exe tools\healthcheck.py
.\.venv\Scripts\python.exe tools\question_audit.py
```

Restart the bot after the checks pass.

## Performance impact

The new `QuestionIndex` avoids repeatedly scanning every bundled question for category and pack lookup. Normal guessing remains fast because guesses only compare against the current board's answers, not the full question pool.

Expected impact with around 5,000 questions:

- startup: slightly more JSON load time
- `/feud_start`: improved category lookup due to indexing
- `/feud_category_preview`: improved category lookup
- `/feud_question_report`: still scans the pool because it is an audit/report command
- `tools/question_audit.py`: longer than before, but acceptable

## Important note

The new boards are survey-style Family Fortunes boards, not quiz facts. The checks validate structure, plausibility, aliases, category fit, scoring shape, and duplicate/sanity issues. They do not claim to be real television survey results.
