# V1.4.4 — Question Admin & Review UI

V1.4.4 adds Discord-side tools for managing the large question pool without opening JSON files during a game night.

## Added

- `tools/apply_v1_4_4_question_admin.py`
- `/feud_question_review`
- `/feud_question_report`
- `/feud_category_list`
- `/feud_category_preview`
- `/feud_disable_question`
- `/feud_enable_question`
- `/feud_alias_cleanup`

## Apply the patch

Run this once after pulling V1.4.4:

```powershell
.\.venv\Scripts\python.exe tools\apply_v1_4_4_question_admin.py
```

Then run:

```powershell
.\.venv\Scripts\python.exe tools\healthcheck.py
```

Restart the bot afterwards so Discord syncs the new slash commands.

## Question review

Use:

```text
/feud_question_review
```

This shows one question at a time with buttons:

- Approve
- Flag
- Edit Needed
- Skip
- Disable Question
- Previous
- Next

The review queue is sorted by quality score, so weaker boards appear first.

## Question report

Use:

```text
/feud_question_report
```

The report shows:

- total questions
- category count
- average quality score
- approved count
- flagged count
- edit-needed count
- disabled count
- low-quality count
- duplicate/self-duplicating alias candidates
- most common categories

## Category tools

Use:

```text
/feud_category_list
/feud_category_preview category:wedding
```

The preview command shows a sample of questions from the category without starting a round.

## Disable / enable questions

Use:

```text
/feud_disable_question search:<question or answer text>
/feud_enable_question
/feud_enable_question index:<number>
```

Disabled question IDs are stored in the bot's existing `ENGAGEMENT_STATE` data under `question_admin`.

The patcher also updates the question picker so disabled questions are skipped during normal round selection.

## Question quality score

The quality score considers:

- answer count
- whether point values descend correctly
- alias coverage
- category validity
- classic survey phrasing
- duplicate answer text

Scores are meant to guide review, not replace human judgement. A weird board may still be funny and worth keeping.

## Alias cleanup

Use:

```text
/feud_alias_cleanup
/feud_alias_cleanup apply:true
```

Dry-run mode reports:

- aliases that duplicate another alias on the same answer
- aliases that exactly duplicate the answer text

Apply mode cleans runtime/custom question aliases where possible. It does not rewrite the bundled JSON files directly.

## Notes

This release is a management/UI patch. It does not change scoring, Fast Money, steals, or team gameplay.
