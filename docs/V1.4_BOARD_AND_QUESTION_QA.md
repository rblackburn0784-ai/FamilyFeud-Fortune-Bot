# V1.4 Board Polish & Question QA

V1.4 focuses on two practical fixes:

1. Strike crosses on the rendered board are changed from font-rendered `X` glyphs to centred diagonal geometry.
2. Question packs now have a dedicated audit tool to find weak, duplicate, odd, or fact/current-sensitive boards.

## Board Strike Alignment

The old board renderer drew strikes using a font glyph. Depending on the font installed on the host machine, the `X` could drift inside the strike boxes.

Run this once after pulling V1.4:

```powershell
.\.venv\Scripts\python.exe tools\apply_v1_4_board_polish.py
```

The patcher replaces the old font-based strike drawing block in `main.py` with centred line-drawn crosses.

Then run:

```powershell
.\.venv\Scripts\python.exe tools\healthcheck.py
```

Start the bot and use `/feud_board` to check the rendered board.

## Question QA

Family Feud / Family Fortunes boards are survey-style. That means most answers are not objectively correct in the same way a quiz answer is correct. They need to be plausible, short, fun, and fairly ranked.

Real Feud/Fortunes boards are based on survey responses, so the right quality target is:

- Does the question make sense?
- Are answers plausible things people would say?
- Are answers short enough to guess naturally?
- Are point values descending and sensible?
- Are aliases helpful without being too broad?
- Are any fact/current-sensitive questions flagged for external checking?

Run the audit:

```powershell
.\.venv\Scripts\python.exe tools\question_audit.py
```

It writes:

- `reports/question_audit_report.md`
- `reports/question_audit_findings.csv`
- `reports/question_web_check_candidates.csv`

Use the CSV files to clean up weak boards over time.

## What the audit checks

- Invalid JSON or invalid row shape
- Missing question text
- Too few or too many answers
- Duplicate questions
- Duplicate answers
- Non-positive or non-integer points
- Points not descending
- Very high or low board totals
- Long/verbose answers
- Vague answers such as `other`, `etc`, `unknown`
- Unknown categories
- Fact/current-sensitive wording needing a web/human check

## Important limitation

The internet can help with factual questions, but it cannot prove every survey answer is “correct”. For survey-style prompts, the best workflow is to run the audit, review the flagged rows, and improve the question pack based on actual Discord play feedback using the existing ratings, alias suggestions, and bad-answer tools.
