# V1.4.2 Board UI Polish

V1.4.2 moves the rendered PNG board into a reusable board renderer and adds preview tooling so layout issues can be checked without running Discord.

## Added

- `feudbot/board_config.py`
- `feudbot/board_renderer.py`
- `assets/board_layout.json`
- `tools/render_board_preview.py`
- `tools/apply_v1_4_2_board_ui_polish.py`

## UI changes

- Strike Xs are drawn as centred diagonal geometry instead of a font-rendered `X`.
- Strike boxes are controlled by layout co-ordinates in `assets/board_layout.json`.
- Revealed answers can show a subtle glow/highlight.
- Long revealed answers shrink to fit the board row more safely.
- Red and Blue score boxes now have team-colour outlines.
- A round-type badge is drawn onto the board.
- Board preview images can be generated locally for visual QA.

## Apply the live bot patch

Run this once after pulling V1.4.2:

```powershell
.\.venv\Scripts\python.exe tools\apply_v1_4_2_board_ui_polish.py
```

Then generate preview images:

```powershell
.\.venv\Scripts\python.exe tools\render_board_preview.py
```

Preview images are written to:

```text
rendered_boards/previews/
```

The preview set includes 0/1/2/3 strikes, partial reveal, completed board, Sudden Death badge, Double Points badge, and Triple Points badge.

## Fine tuning

Most visual nudges should now be made in:

```text
assets/board_layout.json
```

That file controls strike boxes, answer fitting offsets, score outline width, revealed-answer glow, and the round badge placement.

If a future board template changes size or layout, update `assets/board_layout.json` instead of editing `main.py`.
