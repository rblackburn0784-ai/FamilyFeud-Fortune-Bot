# V1.4.5 — Game Night Flow

V1.4.5 turns the bot from single independent rounds into a guided Discord party session.

## Added

- `/feud_game_night`
- `/feud_game_night_score`
- `/feud_game_night_next`
- `/feud_game_night_finish`
- Game Night lobby embed
- Red/Blue team join buttons
- Auto-balance button
- Category voting button flow
- Locked teams after start
- Session score separate from lifetime scores
- Between-round scoreboard
- Round intro messages
- Final winner ceremony
- Awards section

## Flow

```text
Lobby opens
Players join Red/Blue
Category vote
Round 1 — Classic
Round 2 — Double Points style round
Round 3 — Triple Points style round
Fast Money Finale prompt
Winner Ceremony
Next Game Night prompt
```

## Local patch command

Run this once after pulling V1.4.5:

```powershell
.\.venv\Scripts\python.exe tools\apply_v1_4_5_game_night.py
```

Then run:

```powershell
.\.venv\Scripts\python.exe tools\healthcheck.py
```

Then restart the bot.

## Commands

### `/feud_game_night`

Opens a Game Night lobby with:

- Join Red
- Join Blue
- Auto Balance
- Vote Category
- Start
- Cancel

### `/feud_game_night_score`

Shows current session score and current Game Night round progress.

### `/feud_game_night_next`

Host-only command to advance after a round has finished. It starts the next round or moves to the Fast Money finale prompt.

### `/feud_game_night_finish`

Host-only command to post the final winner ceremony and close the Game Night session.

## Awards

The ceremony includes:

- Top Answer Magnet
- Best Steal
- Worst Guess
- Fastest Finger
- The Dude Abides

Some awards become richer as more event tracking is added in future patches.

## Notes

This patch adds a Game Night orchestration layer without removing the normal round-by-round commands.

Double/triple round labels are supported inside the Game Night flow. The patcher applies a session multiplier during Game Night scoring where the known scoring snippets are present, but a future scoring-mode patch can make this more deeply integrated with regular `/feud_start` modes too.

The patcher writes a local backup:

```text
main.py.v1_4_5_game_night_backup
```
