# V1.4.3 — Discord Presentation Upgrade

V1.4.3 improves the in-Discord game presentation without changing the core scoring rules.

## What it adds

- Richer live-round embeds.
- Cleaner `/feud_board` layout.
- New `/feud_live` command for a compact active game panel.
- Active-round buttons:
  - Show Board
  - Join Red
  - Join Blue
  - Scores
  - Host Controls
- Better correct-answer embed.
- Top Answer callout when answer #1 is found.
- Better wrong-answer embed with strike pressure text.
- Better steal incoming embed.
- Better steal result embed.
- Board Clear wording when every answer is found.

## Apply locally

Run this after pulling V1.4.3:

```powershell
.\.venv\Scripts\python.exe tools\apply_v1_4_3_presentation_upgrade.py
.\.venv\Scripts\python.exe tools\healthcheck.py
```

Then restart the bot:

```powershell
.\.venv\Scripts\python.exe main.py
```

Discord should sync a new command:

```text
/feud_live
```

## Notes

The patcher creates a local backup:

```text
main.py.v1_4_3_presentation_backup
```

That backup is ignored by Git and can be used if you need to manually compare or revert the local presentation patch.

This version intentionally avoids adding Double Points / Triple Points mechanics. Those are better handled in a scoring/balance patch so presentation and gameplay changes remain easier to test separately.
