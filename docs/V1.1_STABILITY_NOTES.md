# V1.1 Stability & Repo Hygiene Notes

V1.1 is a safe maintenance patch focused on making the bot easier to clone, run, and keep clean in GitHub.

## Included

- Added `.gitignore` to prevent secrets, virtual environments, Python caches, runtime state, SQLite databases, generated boards, and logs being committed.
- Added `.env.example` with the expected `DISCORD_BOT_TOKEN` setting.
- Updated `README.md` with a V1.1 section, clearer setup, runtime-file guidance, and recommended next steps.
- Added `VERSION` with `1.1.0`.
- Removed committed runtime/cache/generated files:
  - `active_games.json`
  - `engagement_state.json`
  - `server_scores.json`
  - `fortune_bot.sqlite3`
  - `__pycache__/main.cpython-312.pyc`
  - `__pycache__/question_manager.cpython-312.pyc`
  - generated PNGs under `rendered_boards/`

## Not changed in this patch

- No gameplay logic was changed.
- No command behaviour was changed.
- No question packs were changed.
- `main.py` was deliberately left functionally untouched because the current file is large and should be split into modules before heavier code work.

## Recommended V1.2 Direction

1. Split `main.py` into modules.
2. Add a real `/feud_health` command once storage and config helpers are separated.
3. Move persistence to SQLite-first storage.
4. Add visual board themes and branded game-night presentation screens.
5. Add a guided Game Night flow with double/triple points and a final ceremony.
