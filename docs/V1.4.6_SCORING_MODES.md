# V1.4.6 — Scoring Modes & Balance

V1.4.6 makes the round-type badge matter mechanically.

## Added

- Real `double_points` mode
- Real `triple_points` mode
- Cleaner `sudden_death` behaviour
- Balanced `chaos` modifiers
- Steal bonus support
- Round score breakdowns
- Game Night default schedule update

## Scoring modes

### Classic

Standard scoring.

```text
awarded_points = answer.points
```

### Fast Money

Keeps the existing fast-money challenge flow.

### Sudden Death

The first correct answer ends the round. This is already supported by the existing game flow and now appears more clearly in scoring labels.

### Double Points

```text
awarded_points = answer.points * 2
```

### Triple Points

```text
awarded_points = answer.points * 3
```

### Chaos

Chaos now uses weighted modifiers rather than a flat random bonus every time.

Current modifiers:

- Normal Survey — standard scoring
- Mystery Bonus — +10 on correct answers
- Double Dip — answers are worth x2
- Danger Board — +15 bonus
- Steal Pot — successful steals are worth double the revealed board pot

The weighting is intentionally conservative so chaos is fun without becoming completely unfair.

## Game Night default structure

V1.4.6 changes the default Game Night structure to:

```json
{
  "rounds": [
    "classic",
    "classic",
    "double_points",
    "triple_points",
    "fast_money"
  ]
}
```

## Scoreboard logic

V1.4.6 adds helper logic for:

- round points
- team/session points
- scoring mode labels
- bonus points
- steal bonuses
- Fast Money bonus helper

The patch keeps lifetime scoring intact while making the per-round scoring clearer.

## Apply locally

After pulling V1.4.6, run:

```powershell
.\.venv\Scripts\python.exe tools\apply_v1_4_6_scoring_modes.py
.\.venv\Scripts\python.exe tools\healthcheck.py
```

Then restart the bot:

```powershell
.\.venv\Scripts\python.exe main.py
```

/feud_start mode:sudden_death
